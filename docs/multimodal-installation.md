# Multimodal Installation

No OpenCluely setup script, Python environment, donor `.env`, Gemini configuration, or Azure Speech dependency is installed.

The donor source is for review only at `vendor-src/OpenCluely`. Clyra’s desktop development command is `npm run desktop:dev`; packaging uses `npm run desktop:build`. Screen capture uses the operating-system picker and therefore requires the platform’s normal screen-recording permission.
